### 1. Application Form Permanent.pdf
**Source:** Mitra S K Pvt. Ltd.  
**Purpose:** Pre-employment application form completed by candidates before or at the time of joining. Covers the candidate's full personal profile.  
**Pages:** 5  
**Stage:** Pre-joining / at joining

**Sections:**
| Section | Description |
|---------|-------------|
| Header | Position applied for, passport-size photograph |
| Personal Identity | Name (salutation, first, middle, surname), Father's name |
| Address | Present postal address + PIN, Permanent postal address + PIN, Residence/Mobile/Email for both |
| Bank Details | Bank Name, Account Name, Branch Name, Branch Address, Account Number, IFSC & MICR |
| Personal Details | DOB, Date of Joining, Employment Type (Permanent/Contractual), Height (cm), Weight (kg), Blood Group, Age, Religion, Gender, Marital Status, Spouse Name, Spouse DOB, Children (Y/N + no. of sons/daughters), Branch, Department, Designation |
| Identity Documents | Table: Aadhaar, Passport, Driving Licence, Election Card, Ration Card, ESIC Card, Others → Name as on document + Number |
| Declarations (Medical/Legal) | Criminal conviction (Y/N + details), Drug/alcohol abuse (Y/N + details), Pre-existing medical condition (Y/N), Physical defect/disability (Y/N + details) |
| References | Two non-relative references: Name, Company, Address, Relationship, Residence Tel, Mobile Tel |
| Emergency Contact | Name, Address, Relationship, Residence Tel, Mobile Tel |
| Education & Qualifications | Table: Institute/Board, Examination passed, Specification, Year passed, Percentage/Grade |
| Professional Qualifications | Same table format as Education |
| Language Competency | Language, Read (B/I/F), Write (B/I/F), Speak (B/I/F) |
| Employment History | Employer name/city, Dates (From MM/YY – To MM/YY), Position held, Department, Last CTC; Reason for leaving last position |
| Org Chart | Free-draw section for current org position |
| Open Text | Sports/hobbies, Recent operations/surgeries, Significant career achievements, Career objective, Strengths & Areas of Improvement (3 points each), Suitability for position |
| Internal Reference | Is any relative/acquaintance working in the company? |
| Declaration | Signature + Date |
| Enclosures Checklist | Bio data, Age proof, Address Proof, Bank Proof, All Credentials, Two Passport Photos, Payslips (last 3 months), ESIC Declaration, Relieving Letter, Form 11, Aadhaar Card, Disability Certificate |

| Column | Notes |
|--------|-------|
| Name in full with full address of nominee(s) | |

| Age of nominee | |
